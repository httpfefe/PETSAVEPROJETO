# petSave

A new Flutter project.

Este é um projeto de aplicativo desenvolvido para facilitar a busca por receptores compatíveis para doação de sangue de animais de estimação. O objetivo é tornar o processo mais simples e garantir o conforto e o bem-estar dos nossos bichinhos. O app foi criado utilizando Flutter para o desenvolvimento da interface e C# para a implementação do back-end.
